# 🪨 Rock, Paper, Scissors game — Python Beginner Project

A simple command-line implementation of the classic **Rock, Paper, Scissors** game, written in Python using basic `if` statements and the `random` module.

This version is intentionally kept minimal — no functions, classes, or modular code — to make it easier for beginners to understand and build on. 

---

## 🎯 Features

- User vs Computer gameplay
- Input validation
- Random computer choice
- Clear win/loss/tie messages
